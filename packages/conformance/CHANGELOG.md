### Minor Changes

- New packages from the weekend push. @verdocs/vue-sdk: the native Vue 3.5 SDK (script setup SFCs, provide/inject endpoint, TanStack Vue Query with the React SDK's query keys). @verdocs/wc-sdk: the Lit 3 web-components SDK (light DOM, vdocs- tags, custom-elements manifest). @verdocs/conformance grew the template lifecycle and envelope read cases, cross-language fixtures.json, the IMAP helper, and the gated signup E2E lane.
